# Инструкция по созданию базы данных "Божественная Комедия"

## Структура базы данных

### Таблицы

```
parts (части)
├── id
├── name: "Inferno" | "Purgatorio" | "Paradiso"
└── description

cantos (песни)
├── id
├── part_id → parts.id
├── canto_number: 1-34 (Inferno), 1-33 (Purgatorio/Paradiso)
├── title_ru: описание песни на русском
├── title_it: описание песни на итальянском
└── color_hex: цвет песни

terzinas (терцины)
├── id
├── canto_id → cantos.id
├── terzina_number: порядковый номер в песне
├── text_it: итальянский оригинал (3 строки)
├── text_ru: русский перевод (3 строки)
└── color_hex: цвет в формате #RRGGBB
```

---

## Формат SQL-файла

### Именование файлов
```
seed_canto{NN}.sql
```
- `NN` - номер песни с ведущим нулём (01, 02, ... 34)
- Примеры: `seed_canto01.sql`, `seed_canto26.sql`

### Структура INSERT-запроса

```sql
INSERT INTO terzinas (canto_id, terzina_number, text_it, text_ru, color_hex)
SELECT c.id, {НОМЕР_ТЕРЦИНЫ},
'{ИТАЛЬЯНСКИЙ_ТЕКСТ}',
'{РУССКИЙ_ТЕКСТ}',
'{#ЦВЕТ}'
FROM cantos c
JOIN parts p ON c.part_id = p.id
WHERE c.canto_number = {НОМЕР_ПЕСНИ} AND p.name = '{ЧАСТЬ}';
```

### Правила экранирования текста

| Символ | Замена | Пример |
|--------|--------|--------|
| `'` (апостроф) | `''` | `l'amor` → `l''amor` |
| `"` (кавычки) | оставить как есть | `"disse"` |

### Пример терцины

```sql
INSERT INTO terzinas (canto_id, terzina_number, text_it, text_ru, color_hex)
SELECT c.id, 1,
'Godi, Fiorenza, poi che se'' sì grande
che per mare e per terra batti l''ali,
e per lo ''nferno tuo nome si spande!',
'Ликуй, Флоренция, раз ты так славна,
Что на земле и на море ты блещешь,
И даже в Аде ты известна!',
'#722F37'
FROM cantos c JOIN parts p ON c.part_id = p.id
WHERE c.canto_number = 26 AND p.name = 'Inferno';
```

## Исходные тексты

### Расположение файлов

| Файл | Содержание | Кодировка |
|------|------------|-----------|
| `divina_commedia.txt` | Итальянский оригинал | UTF-8 |
| `lyrical_texts_utf8.txt` | Русский перевод (Лозинский) | UTF-8 |

### Структура исходных текстов

Каждая песня начинается с заголовка:
```
Inferno: Canto I
```
или
```
ПЕСНЬ ПЕРВАЯ
```

Терцины разделены пустой строкой. Каждая терцина = 3 строки.

### Поиск начала песни

**Итальянский текст:**
- Искать строку `Inferno: Canto {N}` или `Purgatorio: Canto {N}`
- Текст начинается со следующей непустой строки

**Русский текст:**
- Искать `ПЕСНЬ {РИМСКАЯ_ЦИФРА}` или `АД`, `ЧИСТИЛИЩЕ`, `РАЙ`
- Текст начинается после заголовка

## Система цветов (семантическая)

### Принцип назначения цвета

Цвет терцины определяется по её **эмоциональному и нарративному содержанию**, а не механически.

## Процесс создания SQL-файла

### Пошаговый алгоритм

1. **Найти исходные тексты**
   - Определить номера строк начала песни в обоих файлах
   - Прочитать итальянский и русский тексты

2. **Разбить на терцины**
   - Каждые 3 строки = 1 терцина
   - Последняя строфа может быть 4 строки (добавочная строка)

3. **Сопоставить переводы**
   - Терцина N в итальянском = Терцина N в русском
   - Проверить соответствие по смыслу

4. **Назначить цвета**
   - Прочитать содержание терцины
   - Определить доминирующую эмоцию/образ
   - Выбрать цвет из палитры

5. **Сформировать SQL**
   - Экранировать апострофы
   - Создать INSERT-запросы

6. **Проверить**
   - Количество терцин должно соответствовать оригиналу
   - Все апострофы экранированы

## Задание по оптимизации

### Текущие проблемы

1. **Ручное назначение цветов** — трудоёмко для 4600 терцин
2. **Ручное экранирование апострофов** — возможны ошибки
3. **Ручное разбиение на терцины** — долго и монотонно
4. **Сопоставление переводов** — требует внимания

### Предложения по оптимизации

#### 1. Скрипт автоматического разбора текстов

```python
# Псевдокод парсера
def parse_canto(italian_file, russian_file, canto_num, part_name):
    it_lines = extract_canto_lines(italian_file, canto_num, part_name)
    ru_lines = extract_canto_lines(russian_file, canto_num, part_name)

    tercets = []
    for i in range(0, len(it_lines), 3):
        tercets.append({
            'text_it': '\n'.join(it_lines[i:i+3]),
            'text_ru': '\n'.join(ru_lines[i:i+3]),
            'color_hex': '#5D5D5D'  # по умолчанию
        })
    return tercets
```

#### 2. AI-помощник для определения цветов

Использовать LLM для анализа содержания терцины и автоматического назначения цвета:

```
Промпт: "Определи эмоциональный тон терцины и выбери подходящий цвет из палитры: {палитра}. Терцина: {текст}"
```

#### 3. Batch-генерация SQL

Скрипт, который:
- Читает оба исходных файла
- Автоматически экранирует апострофы
- Генерирует SQL-файлы для всех песен

#### 4. Веб-интерфейс для редактирования цветов

- Отображение терцины с текущим цветом
- Выбор цвета из палитры кликом
- Сохранение изменений в БД

#### 5. Предустановленные цветовые шаблоны

Создать типичные паттерны:
- "Диалог с Вергилием" → автоматически синий
- "Описание наказания" → автоматически красный
- "Переход между кругами" → автоматически серый

### Приоритет оптимизации

| Приоритет | Задача | Эффект |
|-----------|--------|--------|
| 1 | Скрипт парсинга текстов | -80% ручной работы |
| 2 | Автоэкранирование | -100% ошибок апострофов |
| 3 | AI для цветов | -70% времени на цвета |
| 4 | Веб-редактор | Удобная корректировка |
